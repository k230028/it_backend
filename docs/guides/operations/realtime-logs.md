# 실시간 로그 모니터링

관리자 실시간 로그 API는 `V_ITPAPP_LOG_FEED` 뷰를 기반으로 변경 로그 스냅샷을 제공합니다.

- 경로: `GET /api/admin/realtime-logs`
- 권한: `ROLE_ADMIN`
- 필터: 조회 시작 시각, 복합 커서, 테이블, 변경 유형, 건수 제한
- 응답: 증분 행과 최근 구간 집계

같은 시각의 다중 로그를 놓치지 않도록 시각, 로그 테이블 키, 로그 일련번호 복합 커서를 사용합니다. 네이티브 결과의 문자열·시각·숫자 타입은 공통 안전 변환기를 거칩니다.

입력 테이블은 관리자 로그 정의의 허용 키와 교집합을 취하고 변경 유형은 허용 코드만 사용합니다. 응답에는 필요한 표준 로그 필드만 노출하고 변경 전·후 민감 본문을 무조건 포함하지 않습니다.
