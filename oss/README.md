# 백엔드 로컬 저장소 복구 도구

이 디렉터리의 PowerShell 스크립트와 매니페스트는 개발자 로컬 Maven 저장소 및 폐쇄망 반입 미러를 점검·복구하기 위한 비운영 자산이다. 애플리케이션의 Gradle 소스셋과 운영 WAR에 포함하지 않으며 CI 또는 운영 배포 과정에서 실행하지 않는다.

- 백엔드 의존성 관리 담당자가 외부 저장소에 접근 가능한 개발 환경에서만 실행한다.
- 실행 전 스크립트의 삭제·백업 대상과 `GradleUserHome`, `OutDir` 인자를 확인한다.
- 생성 결과는 로컬 복구나 승인된 폐쇄망 반입 절차에만 사용하고 제품 소스 코드로 취급하지 않는다.
- 보안 정적분석 도입 시 `it_backend/oss/**`를 tooling/non-production 제외 목록에 명시한다.
- 도구 삭제 또는 교체는 폐쇄망 반입 절차와 운영 담당자의 사용 여부를 확인한 별도 작업에서 결정한다.
